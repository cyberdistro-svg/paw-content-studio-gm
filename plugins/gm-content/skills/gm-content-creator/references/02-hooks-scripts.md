# 02 — Hook, naskah, CTA

## Rumus hook (Bahasa Indonesia, ≤ 12 kata)

| Rumus | Contoh |
|---|---|
| Kontradiksi | "Makin banyak indikator, makin sering kamu salah entry." |
| Kesalahan umum | "90% trader salah gambar zona supply — ini caranya yang benar." (angka hanya bila ada sumber; kalau tidak: "Kebanyakan trader…") |
| Hasil + waktu | "Tandai zona XAU dalam 3 detik, tanpa gambar manual." |
| Pertanyaan tajam | "Kenapa harga selalu balik pas kamu baru entry?" |
| Rahasia / di balik layar | "Ini yang saya pakai tiap pagi sebelum buka chart." |
| Daftar | "5 alat gratis yang bikin analisa kamu 2x lebih cepat." |
| Visual dulu | (tanpa kata 0,8 s: chart kacau → bersih) lalu "Begini bedanya." |

Hook visual + teks layar + kalimat pertama VO harus **mengatakan hal yang sama**. Buat 3 varian, pilih yang paling spesifik.

## Kerangka naskah short (2,3–2,8 kata/detik)

```
[HOOK 0–2s]      ≤ 12 kata, janji spesifik
[KONTEKS 2–6s]   kenapa ini penting / masalahnya (1 kalimat)
[ISI 6–n]        3 poin maks, tiap poin 1 visual; tunjukkan, bukan klaim
[PAYOFF]         penuhi janji hook
[CTA 2–4s]       satu aksi; untuk broker: "Scan QR / link di bio buat versi lengkap di Telegram"
[DISCLAIMER]     teks layar ≥ 1,5 s: "Edukasi, bukan saran keuangan. Trading berisiko."
```
15 s ≈ 35–40 kata · 30 s ≈ 70–80 kata · 60 s ≈ 140–160 kata.

## Template `naskah.md`

```
JUDUL KERJA  :
FORMAT       : (dari 01-formats)
DURASI/RASIO :
HOOK (3 varian): 1) … 2) … 3) …   → dipilih: …
| t | VO | Teks layar | Visual | SFX |
CTA          :
DISCLAIMER   :
CAPTION POST :
HASHTAG      : 3–6 relevan (#xauusd #belajartrading #forexindonesia …), bukan 30 hashtag spam
COVER        : teks ≤ 4 kata + visual paling kuat
```

## CTA per tujuan

| Tujuan | CTA |
|---|---|
| Lead Telegram (broker) | "Gabung grup Telegram — link di bio / scan QR" |
| Follow | "Follow buat analisa XAU tiap pagi" |
| Save | "Simpan biar nggak lupa pas buka chart" |
| Komentar | "Tulis 'ZONA' kalau mau versi lengkapnya" (hanya bila benar ditindaklanjuti) |
| Produk | "Coba fitur ini di platform" (sesuai materi resmi) |
