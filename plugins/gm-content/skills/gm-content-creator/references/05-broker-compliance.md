# 05 — Program broker & kepatuhan

## Alur kerja konten broker

1. **Brief broker** → tujuan (lead Telegram, deposit, awareness), brand kit, disclaimer regulator wajib, kata/klaim terlarang, kanal.
2. **Kalender** mingguan (lihat `06`) disetujui sekali di awal minggu.
3. Produksi → **antre persetujuan** (persetujuan eksplisit Hendra) → posting.
4. Laporan mingguan: lead Telegram (KPI), views, retensi, konten terbaik → ide minggu depan.

## Aturan kepatuhan (C5)

| Dilarang | Ganti dengan |
|---|---|
| "Pasti profit", "cuan konsisten", "anti loss" | "Cara saya membaca zona", "skenario jika…" |
| Winrate/ROI/hasil tanpa data terverifikasi | Tidak menyebut angka, atau sebut sumber + periode + "hasil masa lalu tidak menjamin hasil masa depan" |
| Screenshot P&L/akun yang tidak bisa dibuktikan | Tidak dipakai |
| Sinyal sebagai perintah ("BUY sekarang!") | "Edukasi: area yang saya pantau, bukan ajakan transaksi" |
| Bonus/promo broker tanpa syarat lengkap | Sertakan "S&K berlaku" + link resmi |
| Menargetkan anak di bawah umur | Konten untuk 18+ |

Disclaimer minimal di setiap konten trading: **"Edukasi, bukan saran keuangan. Trading berisiko tinggi; Anda bisa kehilangan modal."** + disclaimer regulator broker bila disediakan. Untuk TikTok/IG: tambahkan juga di caption.

## Kebijakan platform (cek ulang berkala — kebijakan berubah)

- TikTok/Meta membatasi promosi produk finansial/investasi berisiko; konten edukasi organik umumnya lebih aman daripada iklan langsung. Hindari ajakan deposit eksplisit di konten organik bila brief broker tidak mengizinkan.
- Gunakan label "konten berbayar/kemitraan" platform bila konten dibayar broker.
- Musik hanya dari pustaka resmi platform atau berlisensi.

## Co-brand

Ikuti brand kit resmi GO Markets (clear-space, logo tidak diubah warna/bentuk).
