# 01 — Brief, cerita, storyboard

## Kartu brief (isi semua; yang kosong = tebak terbaik + tulis "asumsi")

```
PRODUK        : (nama persis + versi)
AUDIENS       : (pemula / trader aktif / member broker X / investor)
SATU PESAN    : (1 kalimat — apa yang harus diingat penonton)
BUKTI         : (fitur yang DITUNJUKKAN, bukan diklaim: layar UI, chart, alur)
CTA           : (1 aksi: "Coba gratis", "Join komunitas", "Daftar di broker X")
PLATFORM      : tiktok | reels | shorts | feed | youtube | webinar | iklan
DURASI        : 6 | 10–15 | 20–30 | 45–60 | 90+ detik
RASIO         : 9:16 (default sosial) | 1:1 | 4:5 | 16:9
BAHASA/VO     : id | en ; VO ya/tidak ; caption terbakar ya/tidak
BRAND         : brand kit resmi GO Markets
WAJIB         : (logo, disclaimer, URL, harga)
DILARANG      : (klaim, warna, kata)
```

## Pola cerita (pilih satu)

| Pola | Struktur | Cocok untuk |
|---|---|---|
| **Problem → Reveal → Proof → CTA** | 0–2s rasa sakit; 2–6s produk muncul; 6–n bukti kerja; akhir CTA | indikator, webapp, promo umum |
| **Before / After** | layar kacau → satu gerak transformasi → layar rapi | indikator chart, dashboard |
| **Walkthrough 3 langkah** | "1. … 2. … 3. …" tiap langkah = 1 scene UI | onboarding app, tutorial broker |
| **Hero object** | satu objek (logo/maskot/HP) jadi pusat, kamera mengitari, fitur muncul sebagai label | app mobile, launch |
| **Data story** | satu angka/grafik bertumbuh, makna dijelaskan | edukasi, laporan pasar (data NYATA saja) |
| **Countdown/launch** | teaser 3–5 beat cepat, reveal nama, tanggal | peluncuran produk, webinar |
| **List cepat** | "5 hal…" dengan nomor bergerak (lihat referensi web.tactics) | konten edukasi viral |

Aturan hook (0–1,5 s): frame pertama sudah berisi pertanyaan/klaim visual kuat; teks besar ≥ 100 px (1080 lebar); gerak langsung.

## Storyboard — format tabel wajib

| t (s) | Visual | Teks layar | Gerak (ease/durasi) | Suara |
|---|---|---|---|---|
| 0.00–1.30 | latar Arctic Prism, kata besar | "Chart penuh garis?" | kata stagger 0.11s, softLand 0.36s, dari 1.6× + blur | hit |
| 1.30–2.40 | … | … | cut on motion (keluar exitIn 0.2s) | whoosh |

Durasi beat: 0,8–2,5 s untuk sosial; scene hero boleh 3–5 s asal ada gerak sekunder (kamera push, data tergambar).
